## 使用與維護

- 與 AI 協作時，提供本 README 內容或連結，並確認 AI 能讀取目前版本；本倉庫不會自動同步到所有 AI。
- 在 [Issues](https://github.com/WalterC801029/ai-personal-profile/issues) 建立待辦，寫明目標、驗收條件與相關章節；完成更新後附上 commit 連結並關閉 Issue。
- 每次修改以 Git commit 記錄目的；在 GitHub 的 History 或本機 `git log --oneline` 查看歷史。
- 如需撤銷某次已提交修改，使用 `git revert <commit-SHA>` 新增反向提交，再執行 `git push`，保留原有歷史。

### 本地同步

首次下載：

```powershell
git clone https://github.com/WalterC801029/ai-personal-profile.git
cd ai-personal-profile
```

每次編輯前，先在工作目錄乾淨時更新：

```powershell
git pull --ff-only
```

修改 README 後提交並推送：

```powershell
git diff
git add README.md
git commit -m "docs: 更新個人檔案"
git push
```

本機未提交的編輯不會自動進入 Git 歷史；推送需要具有此倉庫寫入權限的 GitHub 身分驗證。
